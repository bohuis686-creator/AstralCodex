# 来源与素材

本项目的窗口发现、DWM 实时缩略图、窗口几何与 Windows 应用激活接口代码改编自 [Codex-WhiteDragon-AutoLaunch](https://github.com/suyuan132/Codex-WhiteDragon-AutoLaunch)，遵循 MIT 许可证。原版权声明保留在 LICENSE 中。

角色参考插画通过 OpenAI 图像生成工具生成。`media/startup.mp4` 由用户通过豆包生成并提供，包含视频自带音轨。旧版 `startup.wav` 由程序合成。AI 生成素材的使用和分发适用其来源服务条款，代码的 MIT 许可证不替代素材条款。

项目为社区开发的 Codex 兼容工具。OpenAI、Codex、ChatGPT、Microsoft、Windows 名称及相关商标归各权利人所有。运行依赖用户自行安装的 Codex、Windows、.NET Framework/WPF 和 DWM，相关组件适用其自身条款。
