## 星澜预览版 / Astral Codex preview

下载 `AstralCodex-Windows.zip`，完整解压到固定目录，运行 `Preview.cmd` 预览或 `AstralCodex.exe` 启动 Codex。`Install-Desktop.cmd` 接入已有桌面快捷方式，`Restore-Desktop.cmd` 恢复备份。保留 `.integration` 文件夹。

包含 1080p 二次元动态视频与音轨、窗口等待及展开过渡、音量控制和 Esc 跳过。需要 Windows 10/11 x64、.NET Framework/WPF、媒体组件和已安装的 Codex。

已通过本地编译、自测、动态预览和已打开 Codex 的窗口交接。冷启动、不同 DPI、多显示器及不同安装版本仍欢迎测试。

Download and fully extract the Windows ZIP to a permanent folder. Run `Preview.cmd` or `AstralCodex.exe`. Desktop integration and backup restoration are included. Requires Windows 10/11 x64, .NET Framework/WPF, media components and installed Codex.

Locally verified with build checks, video preview and handoff to an already-open Codex. Wider startup and display compatibility testing is welcome. This is an early preview.
